# Sobre o Foco
Organizador de estudos com barra de progresso. Projeto individual em HTML, CSS e JavaScript puro, com API no mockapi.io.

**Curso**: Técnico em Informática para Internet · Módulo II
**UCs**: Codificação para Front-End · Interação com APIs

## Tema e campos

Recurso no mockapi.io: `estudos`

| Campo | Tipo | Opções |
|---|---|---|
| assunto | texto | |

| horasPlanejadas | número | |
| horasEstudadas | número | |
| prazo | texto | |
| status | texto (select) | A estudar, Estudando, Revisando, Concluído |
